# Call App 📞

A cross-platform Flutter application designed to initiate phone calls directly from the app. 

## Features
* **Cross-Platform Support:** Fully configured for Android, iOS, Web, macOS, Linux, and Windows.
* **Native Dialer Integration:** Seamlessly triggers the device's default phone dialer.
* **Clean Structure:** Modular codebase for easy scaling and feature integration.

## Prerequisites
Before you begin, ensure you have the following setup:
* [Flutter SDK](https://docs.flutter.dev/get-started/install) (latest stable version)
* An IDE with Flutter and Dart plugins installed (e.g., VS Code, Android Studio)
* A connected physical device or emulator for testing
